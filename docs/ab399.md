# `D₅(Q) = 1` for `Q_ab ≅ C₃ × C₉ × C₉` (class ≤ 4): the proof on paper

This result is **not in the paper** (S. Vorobev, *On the inclusion `D₅(G) ⊆ γ₄(G)`*,
https://ispacex.github.io/d5), and the paper is not being changed to include it. This note is the
public account of its proof on paper, from the author's research notes (2026-11-12); it is
formalized in this repository as `GroupDimension.D_five_eq_bot_of_class_four_ab399`
(`TaharaTheorem.lean`; proof in `Star/`, `Star.lean`, `Ab399.lean`, `Ab399Finite.lean`) and is
the fifteenth statement compared for Palomar (`Challenge.lean`).

**Provenance.** The argument was first drafted by the model Kimi K3.1 Pro (Moonshot AI, through
Open Math OS) at the author's direction, then corrected after one independent agent review. No
human expert has reviewed it. The Lean proof was written by Kimi K3.1 Pro agents against
statements fixed by a Claude Code agent and checked by the Lean kernel; it uses only `propext`,
`Classical.choice` and `Quot.sound`. Novelty is not claimed.

**Theorem.** Let `Q` be a finite group of class `≤ 4` with `Q/γ₂(Q) ≅ C₃ × C₉ × C₉`. Then
`D₅(Q) = 1`. There is no condition on `γ₄(Q)`.

(`Q` is then a 3-group: it is nilpotent, so the product of its Sylow subgroups, and a nontrivial
Sylow `p`-subgroup with `p ≠ 3` would give a nontrivial `p`-part of `Q/γ₂(Q)`.) When
`γ₄(Q)³ = 1` the theorem is a case of the paper's Theorem 6.11; the new case is `γ₄(Q)` of
exponent 9, e.g. `γ₄(Q) ≅ C₉`, which Remark 6.13 of the paper leaves open.

## Setting (from the paper, §6, proof of Theorem 6.11)

Notation as in the paper: Tahara's uniqueness bases `x_i` (first layer, `x_i` of order
`d(i) = 3^{α_i}` modulo `γ₂`, `d(i) ≤ d(j)` for `i < j`), the commutators `c_{ij}` and their
classes `c̄_{ij}` in `L₂ = γ₃/γ₄`, `Y_i = x_i^{d(i)} ∈ γ₂` with class `Ȳ_i`, the bilinear map
`ω : L₂ × L₂ → γ₄`, `ω(ā, b̄) = [a, b]`, the ternary form `t`, and Tahara's generator `g(τ)` of
`D₅` for an integer family `τ` satisfying his conditions (A)–(F) (Tahara 1981, Theorem 6.1, the
inclusion part, formalized as `taharaFiveOne`). The basis is adapted as in step (4) of the
proof of Theorem 6.11: the index set is split as `A ⊔ N` with `Ȳ_h ∈ 3L₂` for `h ∈ N`, and the
congruences (c1)–(c3) hold.

**The exact identity (⋆).** Steps (1)–(3) of the proof of Theorem 6.11 do not use the exponent
of `γ₄` (Remark 6.13). Read through any map `A` additive on `γ₃`, they give, for every `τ`
satisfying (B), (D₂), (E), (F₂),

    2 A(g(τ)) = T₁ + T₂ + T₃ + T₄ + T₅,

with explicit sums `T₁, …, T₅` of values of `ω` and `t` (Lean: `Star.two_smul_gen_eq`, for any
group of class `≤ 4` with Tahara's data; the row identity `Star.row_exact` and the `v`/`w`
parts `Star.v_exact`, `Star.w_exact` are exact, with no reduction modulo 3).

## The proof

Let `d = (3, 9, 9)`, indices `1, 2, 3`.

1. **`T₅ = 0`**, as `d(i) ∣ binom(d(i), 2)` and `[R, x_i, x_i]^{d(i)} = 1` (K4).
2. **Every term with the index `1` vanishes** (`d(1) = 3`): `c̄_{1h}` has order dividing 3 in
   `L₂` (as `x₁³ ∈ γ₂`), so the relevant value of `ω` or `t` is killed by 3, and each
   coefficient carries a factor 3 by (c1)–(c3), or `Ȳ_h ∈ 3L₂` when `h ∈ N`.
3. **What remains is the pair `(2, 3)`** (`d = 9, 9`). By (c1), `u₂₃ = 3U`. With
   `Ω_h = ω(c̄₂₃, Ȳ_h)`, `𝒜 = [Y₂, x₃, x₂]`, `ℬ = [Y₃, x₂, x₃]`: `T₁ = 3U · 4 (Ω₂ − Ω₃)`
   (the `t`-part of `T₁` vanishes), `T₂ = −3U Ω₃`, `T₃ = −w'₂₃₃ ℬ`, `T₄ = 0`; by (K5) and
   `[Y₂, x₂] = [Y₃, x₃] = 1`, `𝒜 = Ω₂` and `ℬ = −Ω₃`. So
   `2g = 12U 𝒜 + (15U − w'₂₃₃) ℬ`.
4. **`ω(c̄₂₃, ·)` is 3-torsion.** `L₂` is generated by `c̄₁₂`, `c̄₁₃` (of order dividing 3) and
   `c̄₂₃`, and `ω(c̄₂₃, c̄₂₃) = 0`. Hence `3𝒜 = 3ℬ = 0` and `ω(c̄₂₃, 3L₂) = 0`, so
   `2g = −w'₂₃₃ ℬ`. If `ℬ ≠ 0` then `Ȳ₃ ∉ 3L₂`, i.e. `3 ∈ A`, and (c3) gives `3 ∣ w'₂₃₃`.
   So `2g = 0` (Lean: `Ab399.Setup.T1_eq` … `T5_eq`, `Ab399.Setup.omega_three`).
5. `γ₃` has odd order, so `g(τ) = 1` for every admissible `τ` (`Ab399.Setup.gen_eq_one`), and
   `D₅(Q) = 1` by the inclusion part of Tahara's Theorem 6.1. The finite theorem
   (`Ab399Finite.lean`) builds the bases from `Q_ab ≅ C₃ × C₉ × C₉` and derives `d = (3, 9, 9)`.

Only this finite form is formalized; the general form `D₅(G) = γ₅(G)` whenever
`G/γ₂(G) ≅ C₃ × C₉ × C₉` (through `G/γ₅(G)`, as in the paper) is not.
