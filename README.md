# group-dimension — dimension subgroups of groups in Lean

[![CI](https://github.com/ispacex/group-dimension/actions/workflows/ci.yml/badge.svg)](https://github.com/ispacex/group-dimension/actions/workflows/ci.yml)

The Lean formalization accompanying the paper *The $D_5$ problem* (PDF:
[English](https://ispacex.github.io/d5/paper/d5.pdf), [Russian](https://ispacex.github.io/d5/paper/d5-ru.pdf);
site <https://ispacex.github.io/d5>). The computations, notes and the formalization audit are in
<https://github.com/ispacex/dimension-subrings>, where this package is the submodule `groups/` (it was developed there; the history
is kept here).

## Use as a dependency

```toml
[[require]]
name = "group-dimension"
git = "https://github.com/ispacex/group-dimension"
rev = "main"
```

then `import GroupDimension`.

The statement of Problem 20.84 of the Kourovka notebook — **is $D_5(G) \subseteq \gamma_4(G)$ for
every group $G$?** — in Lean 4 / Mathlib, with the basic facts fully proved and a comparison with
the Lie ring case, which is proved and formalized in [IMP26] (arXiv:2610.02042, repository
<https://github.com/TimmPeterson/lie-algebras>).

Lean `v4.35.0`, Mathlib `v4.35.0` (rev `56a0058`); every file uses the Lean module system
(`module`, `public import`, `@[expose] public section`). Mathlib is the only dependency.

**Lean 4.29 → 4.35 and the `lie-rings` dependency.** Up to commit `e58aa2b` (tag `lean-v4.29`)
the package was on Lean/Mathlib `v4.29.0` and required the authors' package `lie-rings`
(TimmPeterson/lie-algebras at `ed3d9fb`, also on 4.29), used only by `LieComparison.lean` for the
Lie-ring theorem `lieDimensionQuestion5`. For the port to 4.35 (needed for the
[Palomar](#palomar-registry-submission) submission) that dependency was **dropped**, not vendored:
the repository has no licence file, so its code may not be copied here; it is on 4.29 and about
2.3 MB of Lean, and we cannot push a port upstream. `LieComparison.lean` keeps the group-side
formulations and quotes the Lie statement; `lieDimensionQuestion5` can be checked at `e58aa2b`.
Theorem statements are otherwise unchanged; the only systematic change is Mathlib's renaming of
`lowerCentralSeries G k` to `(⊤ : Subgroup G).lowerCentralSeries k` (the same subgroup).

## Definitions (`GroupDimension/Basic.lean`)

| In the paper | In Lean |
|---|---|
| $\mathbb Z[G]$ | `MonoidAlgebra ℤ G` |
| $\varepsilon\colon \mathbb Z[G]\to\mathbb Z$, $g\mapsto 1$ | `augmentation G := (MonoidAlgebra.lift ℤ ℤ G 1).toRingHom` |
| $\Delta(G)=\ker\varepsilon$ | `augIdeal G := RingHom.ker (augmentation G)` — an `Ideal`, with an `IsTwoSided` instance |
| $D_n(G)=\{g \mid g-1\in\Delta^n\}$ | `D n G : Subgroup G`, `mem_D` — by definition (`Iff.rfl`) |
| $\gamma_n(G)$, $\gamma_1=G$ | Mathlib `(⊤ : Subgroup G).lowerCentralSeries (n-1)` |
| $H^m$, the subgroup generated by $m$-th powers | `powSubgroup H m` |
| $P_n(G)$, lower exponent-$p$ central series: $P_1=G$, $P_{i+1}=[P_i,G]P_i^p$ | `expCentral p G n` (also $P_0=G$) |
| $M_n(G)=\prod_{ip^j\ge n}\gamma_i^{p^j}$ | `jennings p G n` — the **Jennings–Lazard formula taken as the definition**; that it equals $G\cap(1+\Delta_{\mathbb F_p}(G)^n)$ (the paper's definition) is Jennings' theorem. Its hard inclusion is proved for the case the paper needs, $p=2$, $n=5$, class $\le3$: $G\cap(1+\Delta_{\mathbb F_2}^5)\le$ `jennings 2 G 5` (`mem_jennings_of_sub_one_mem`, `Jennings/`); in general it is proved with the Lazard series in place of the product, and that the two agree (Lazard) is not formalized |
| candidate (§5, before Lemma 5.6) | `IsCandidate Q n` (`Candidate.lean`) |

**Numbering of the lower central series.** In Mathlib (`Mathlib/GroupTheory/Nilpotent.lean`)
`S.lowerCentralSeries 0 = S`, `S.lowerCentralSeries (k+1) = ⁅S.lowerCentralSeries k, S⁆`, and for
`S = ⊤` **`(⊤ : Subgroup G).lowerCentralSeries k` = $\gamma_{k+1}(G)$**: $\gamma_2$ =
`(⊤ : Subgroup G).lowerCentralSeries 1` (= `commutator G`, `Subgroup.top_lowerCentralSeries_one`),
$\gamma_4$ = `(⊤ : Subgroup G).lowerCentralSeries 3`. (Before Mathlib 2026-05 this was
`lowerCentralSeries G k`.) The numbering
of `D n G` follows the literature, with no shift ($D_0 = D_1 = G$).

**Commutator.** In Mathlib `⁅a, b⁆ = a b a⁻¹ b⁻¹`. The identity in $\mathbb Z[G]$:
$[a,b]-1 = \bigl((a-1)(b-1)-(b-1)(a-1)\bigr)\,a^{-1}b^{-1}$. For the paper's convention
$[a,b]=a^{-1}b^{-1}ab$ — $[a,b]-1 = a^{-1}b^{-1}\bigl((a-1)(b-1)-(b-1)(a-1)\bigr)$, as in the
statement of the problem. Both identities are proved (`of_commutator_sub_one`,
`of_inv_mul_inv_mul_mul_sub_one`).

## Certificates for Proposition 5.3 (order $2^{10}$; `GroupDimension/Cert1024/`, D5-34)

The computational part of Proposition 5.3 is that each of the $3400$ candidates of order $2^{10}$
has $D_5 = 1$. Here it is checked in Lean from certificates, independently of the lattice
computation. The data are generated by `compute/cert1024` of
[dimension-subrings](https://github.com/ispacex/dimension-subrings).

* **The group.** Data line $i$ is the ANUPQ pc presentation of
  `PqDescendants(SmallGroup(512, parent) : StepSize := 1)[k]` on $g_0,\dots,g_9$ (relative orders
  $2$). `cand i` is the group *defined by this presentation* (`PcGroup`, a `PresentedGroup`).
* **The certificate.** A finite abelian group $V=\bigoplus_{i<r}\mathbb Z/2^{a_i}$ (here $r\le19$)
  and integer matrices $C_0,\dots,C_9$.
* **The check** (`checkAux`, file `Cert1024Comp.lean`, core Lean only): the presentation has pc
  shape; each $C_k$ is well defined and invertible on $V$; the $C_k$ satisfy the relations on $V$;
  $\Delta^4V=0$; and the $2^{10}$ normal words act by distinct operators. $\Delta^4V=0$ is checked
  on spanning sets (`nilSpan`): $B_0$ is the standard basis, $B_{d+1}$ consists of the vectors
  $(C_k-1)b$ ($b\in B_d$) reduced against each other, zero remainders dropped, and the check is
  $B_4=\varnothing$. This is 371 matrix–vector products per candidate on average (at most 790) instead of the
  $10^4$ products $(C_{k_1}-1)\cdots(C_{k_4}-1)$; `nilSpan_sound` proves that it implies that every
  such product vanishes on $V$.
* **Soundness** (no extra axioms): `exists_nwFrom_zero` (every element of a pc-presented group is a
  normal word, `PcBound.lean`), `map_eq_one_of_mem_D` (a representation in which products of $k$
  factors $\rho(s)-1$ vanish kills $D_k$, `Nilpotent.lean`), `D_four_eq_bot_of_checkAux`,
  `nilSpan_sound`, `D_five_candGroup` (`Check.lean`, `Decode.lean`). A passing check gives a faithful
  representation that kills $D_4$, so $D_4=D_5=1$ and $|Q| = 2^{10}$.
* **The data** (`Data/C00.lean`–`C33.lean`, 100 lines each): `cXX_ok : cXX.all checkStr = true` by
  **`native_decide`**. The checker is in the library `Cert1024Comp`, which has
  `precompileModules = true`, so `native_decide` runs it as native code. Interpreted, 7 candidates
  took more than 14 minutes. Compiled, the 34 chunks take 19 CPU-minutes (3.5 min on 6 cores;
  with the unpruned nilpotency check it was 2.2 CPU-hours, 23.5 min). `Test/Tamper.lean` (a
  separate CI step) contains negative controls: corrupted lines, a non-pc presentation and $D_{32}$
  (where $D_4\ne1$) each fail the part of the check they should, as does the real line with $C_0$
  replaced by a $3$-cycle (not unipotent); and `nilSpan` agrees with the
  unpruned check `nilFull` at depths $0,\dots,6$ on Jordan blocks, cyclic modules, a
  mixed-valuation module, 40 pseudo-random certificates and (depths $\le5$) a real line.
* **Proposition 5.3** (`Prop1024.lean`): `D_four_cand`, `D_five_cand : ∀ i, D 5 (cand i) = ⊥`, `card_cand : Nat.card (cand i) = 2 ^ 10`, and
  `prop_1024`: $D_5(R)=1$ for every $R$ of order $2^{10}$ with $\gamma_4(R)=1$, from three explicit
  hypotheses: `hD3` ($D_3=\gamma_3$), `h512` (Prop. 5.1 at order $2^9$, a computation) and
  `hcomplete` (every `IsCandidate` group of order $2^{10}$ is isomorphic to some `cand i`; this is
  the ANUPQ search together with Lemma 5.2(d), not certified). `D_five_eq_bot_of_rank_of_complete`
  is Proposition 5.7 with `h1024` replaced by these hypotheses.
* **Build**: the data are not imported by `GroupDimension.lean`; CI builds them in a separate step,
  `lake build GroupDimension.Cert1024.Prop1024`, then runs `lake env lean AxiomAuditCert1024.lean`. The audit shows `propext`, `Classical.choice`, `Quot.sound` and the 34 axioms that `native_decide` introduces, one per chunk (under Lean v4.35 they are named `_private.GroupDimension.Cert1024.Data.CXX.0.….native_decide.ax_1_1`); CI allows nothing else and checks that `prop_1024` depends on all 34.

## Comparison with Lie rings (`LieComparison.lean`)

The file puts the Lie statement (quoted from [IMP26]; up to `e58aa2b` it was imported from
`LieRings.Publication.Results` and `lieDimensionQuestion5` was proved from `corollaryD`) and the
group statement `DimensionQuestion5` (open) side by side and discusses
in a comment which steps of §§5–6 of the paper carry over. In short:

* **carry over**: passing to a quotient (Corollary 6.14; for groups proved here —
  `dimensionQuestion5_iff`), reduction to finitely generated (Lemma 6.13), the construction of the
  central extension $T = G\times_{G_{ab}}P$ (but $T'\to T\to P$ splits as a semidirect, not a
  direct product);
* **no direct analogue**: the PBW filtrations $P_{\le r}U(T)$ with $\mathrm{gr}\cong\mathrm{Sym}$
  and the basis of ordered monomials (Thm 2.3, Cor 2.4); the additive retractions
  $p\colon U(T)\to P_{\le2}U(T)$ and $r\colon P_{\le2}U(T)\to T$ (Thm 5.1, Lemma 5.3), which rest
  on $T\subset U(T)$ being an additive subgroup: for groups the embedding $g\mapsto g-1$ is
  additive only modulo $\Delta^2$; the explicit $\mathbb Z$-description of $\Delta(T)^n$ on which
  the retraction $p$ is built (Prop. 6.12).

## Paper labels and contributing

Each declaration named in a node of the blueprint (a labelled statement of the paper) carries
`@[d5 "<label>"]` (`GroupDimension/D5Tag.lean`), e.g. `@[d5 "thm:g4cube"]`, the label of the
statement on [blueprint.html](https://ispacex.github.io/d5/blueprint.html); the attribute also
takes permanent tags `D5:XXXX` (`@[d5 000P]`), to which the labels will move. `#d5_tags`
(`lake env lean D5Tags.lean`) lists them all, as JSON. The source of truth is `site/blueprint.toml` of
dimension-subrings, whose CI fails unless the tags are exactly its (label, declaration) pairs. How
to claim a statement and contribute (blueprint → claim → pull request → review, and how AI-written
code is labelled): [CONTRIBUTING.md](CONTRIBUTING.md).
